Privacy Notice — Shreeji Marketing

Last updated: 18 November 2026

Shreeji Marketing Tiles Management System is a private business tool intended for two authorized users to manage tile inventory, batches, sales, dealer/customer balances, payments, returns, damaged stock and reports.

What the application does

The website is delivered as static HTML and JavaScript. GitHub Pages hosts those website files. GitHub Pages is not used as the business database. The application connects directly from the user's browser to Google Drive using Google's OAuth authorization and Drive API.

Business data

When configured, business records are stored in the “Shreeji Marketing Data” folder in the Google Drive account selected by the Administrator. This can include design and stock records, sales invoices, customer/dealer details, payment records, returns, damage records, audit events, user configuration, backups and reports. The application does not intentionally upload those business records to the website hosting repository.

Google Drive permission

This version requests the Google Drive scope https://www.googleapis.com/auth/drive. Google describes this permission as broad access to view, edit, create and delete files in the authorizing account's Drive. The app's normal workflows use the Shreeji Marketing Data folder, but the OAuth grant itself is not restricted to that folder. Only authorize it if you accept this permission. You can review or revoke the application's access in your Google Account security settings.

Credentials and access

The Google OAuth access token is held in browser memory by this version and is not deliberately written to the Drive business files. The OAuth Client ID and selected Drive folder identifier are saved in that browser's local settings. App login credentials are stored in the Drive configuration as salted password hashes. Do not share the Drive folder with anyone other than the two intended Google accounts.

Hosting and browser data

GitHub Pages serves this public website and may process technical request information such as IP addresses under GitHub's own privacy and security practices. Browser local storage is used for app preferences and connection identifiers. The app also loads Google's official Identity Services JavaScript library to authorize Drive access.

Limitations

The app is a direct-to-Drive browser application. Its Staff/Admin controls are app workflow controls; a Google Drive Editor can still manipulate files directly in Drive outside the app. Drive file operations and the app's advisory write lock do not provide database-grade atomic transactions. Do not perform stock-changing transactions simultaneously on both computers.

Contact

For privacy questions about this private business tool, contact the Shreeji Marketing Administrator directly.

This notice describes the current application package and its direct-to-Google-Drive design. It is not a statement that Google or GitHub endorses the application.
